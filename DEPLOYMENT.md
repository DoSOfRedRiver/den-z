# День Z: локальный деплой

- HTTPS: `https://92-118-205-5.sslip.io/` → Caddy (`caddy-den-z.service`, ports 80/443).
- Статика: `/srv/den-z/www`; определения уроков: `/srv/den-z/lessons`.
- API: `den-z.service`, loopback `127.0.0.1:8765`, доступ извне только через `/api/*` за Caddy.
- Приватное состояние: `/var/lib/den-z/progress.sqlite` и `/var/lib/den-z/token` (директория доступна `denz` и root; никогда не коммитить и не копировать в web root).
- Авторизация: личная ссылка с `#key=...` сохраняет ключ в localStorage данного браузера и удаляет фрагмент из адресной строки. API принимает `Authorization: Bearer ...`. Владение личной ссылкой эквивалентно доступу к результатам; при утечке заменить ключ и перезапустить `den-z.service`.

## Обновление урока

В `/root/projects/den-z`: добавить `lessons/YYYY-MM-DD.json`, затем `python3 publish.py && python3 deploy.py /srv/den-z`. Проверить HTTPS `index.html` и конкретный `/lessons/YYYY-MM-DD.html`, а также `curl -o /dev/null -w '%{http_code}' https://92-118-205-5.sslip.io/api/progress` → `401` без ключа. Коммитить только исходник и публичную статику. Не пушить прогресс на GitHub.

## Откат

1. При проблеме только с уроком: восстановить предыдущий локальный коммит `main` в отдельной временной копии и повторить `publish.py` + `deploy.py`; исходные файлы/DB не перезаписывать из отката.
2. Остановить внешний доступ: `systemctl stop caddy-den-z.service`; API и SQLite остаются на машине. Для полного отключения: `systemctl disable --now caddy-den-z.service den-z.service`.
3. Восстановить публичную альтернативу только осознанно: GitHub Pages отключён, а прежний репозиторий не содержит приватных результатов.
4. Сохранить копию SQLite с помощью `sqlite3.Connection.backup()` перед переносом или восстановлением сервера; не копировать живой файл SQLite без согласованного снимка.

Ограничения: `sslip.io` зависит от неизменности публичного IP этой машины и стороннего DNS. Открытый ответ сохраняется с `pending` и требует экспертного разбора; автоматический балл относится только к выбору вариантов.
